PALM SETU – SOULMATE SKETCH LIBRARY

This pack contains 118 portrait assets and sketch_catalog.csv.

IMPORTANT:
- The first 98 files are individual crops from a generated contact sheet. They are thumbnail-grade assets, enlarged for app integration; inspect them before using as full-screen premium portraits.
- The remaining 20 files are standalone portrait images from the earlier pack.
- Gender, age-range and country tags are routing metadata for illustrative matching only. They are not verified attributes of the fictional portraits and should not be presented as factual ethnicity, nationality, age, or predictions.
- No image-generation API is needed at runtime. Store the chosen filename and questionnaire answers so the same user sees the same portrait on refresh.
